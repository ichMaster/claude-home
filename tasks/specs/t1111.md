# t1111 — the Prompt screen understated the live prompt by 36 %

Found by the full review, 2026-11-01 (truth H2, M6, M7, M10 in
`status/state/code-review/2026-11-01-panel-full-truth.md`).

## Problem

The screen's claim is «тут видно те, що бачить сесія». It showed 9 598 characters of a
15 033-character prompt.

`start.sh` **moves** `memory/handoff.md` to `handoff-last.md` as it reads it. So the file
being absent is the proof that the running session *carries* the note — and the screen read
that absence as "there is no handoff part", with the module docstring stating the inverted
reasoning outright. This session is exactly that case: the note was archived four seconds
before the session came up, and 5 403 characters of it — the whole thread of yesterday — were
missing from the composition table, from the total, from the token estimate and from the
`<pre>` block.

Three smaller untruths on the same screen:

- the handoff block was joined with a single `\n`, while the shell writes a blank line and
  the heading `## Естафета з попередньої сесії` before it — so even the state the screen was
  designed for was not what the session sees;
- an **unknown** session start time rendered as the positive claim «усе … не змінювалось
  після старту сесії» (M6);
- the restart banner watched `persona.md`, `CLAUDE.md` and the facts, but not the
  configuration or the permission block — which are read at launch too, and which three
  places on the panel promise the banner covers (M7);
- `/prompt` and `/rules` each appended to `sys.path` per request — the leak t1067 and t1071
  closed on two other screens (M10).

## Fix

- `handoff_state()` answers in four states: `pending` (the file is still there, so the *next*
  start takes it), `consumed` (archived before this session came up — this session has it),
  `unknown` (the archive is newer than the session's start, so it is not this session's), and
  `none`. The screen says which, in words, because the file's absence means the opposite of
  what it looks like.
- `assembled()` writes the blank line and the heading, and strips trailing newlines from each
  part exactly as command substitution does, so the total is the shell's arithmetic. Verified:
  the screen and a script replaying `start.sh`'s own construction now agree at 15 033.
- The banner says «час старту невідомо» instead of claiming freshness, and watches
  `config.json` and `config.local.json` as well.
- `_on_path()` adds a directory once.

## Test cases

- **TC1 —** a consumed note is part of the prompt and is marked consumed. (Fails before.)
- **TC2 —** a pending note is marked pending; an archive newer than the session's start is
  not claimed; no note at all says so.
- **TC3 —** the assembled text carries the heading, and equals what the shell would build,
  character for character.
- **TC4 —** an unknown start time renders as unknown, not as "nothing changed".
- **TC5 —** a changed `config.local.json` asks for a restart.
- **TC6 —** repeated requests to both screens leave `sys.path` unchanged.
