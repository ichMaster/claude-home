# t1038 — Bruno does not inherit the search area on a follow-up

## Problem

"подивись в ютюбі про X" classified as `scope: youtube` correctly. The follow-up "спробуй так
Y" (rephrase, no area named) fell back to `scope: both`, so Bruno answered with news for a
YouTube-only request (observed 2026-10-31 in Bruno's chat).

## Test cases

- **TC1 —** previous area `youtube`, message rephrases without naming an area ("спробуй так …")
  → scope stays `youtube` (regression).
- **TC2 —** previous area `youtube`, message names a new area explicitly ("знайди новини про …")
  → scope switches to `news`.
- **TC3 —** no previous area, plain topic → scope decided from the message alone.

## Approach

`intent(message, prev_scope)` passes the previous area to the classifier; `intent.md` returns
`keep_scope` and the loop keeps `prev_scope` when the message is a bare continuation. The area
of each search is stored in the bot state as `last_scope`.
