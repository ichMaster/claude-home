# t1233 — «на вихідних» said on a Sunday books next weekend

## Problem / goal

`parse_period`'s weekend branch computes `sat = today + (5 - weekday) % 7`, which on a
Sunday gives +6 days: «перебрати акваріум на вихідних», said on Sunday 2026-11-22,
stores the period 2026-11-28..29 — a week away — although the weekend the user means is
still running. The sibling «цього тижня» branch has an explicit Sunday special-case
(«неділя: цього тижня = наступні сім днів»); the weekend branch got none. The task
silently drops out of the today/this-week horizon and resurfaces a week late.
(Reproduced live: opening this very task on a Sunday stored period 11-28..29.)

## Test cases

- **TC1 — regression:** on a Sunday, «на вихідних» returns the weekend in progress
  (yesterday's Saturday .. today).
- **TC2 —** on a Saturday it stays today..tomorrow; on a Friday the coming
  Saturday..Sunday — unchanged.
- **TC3 — edge:** on a Monday the coming weekend, five days ahead — unchanged.

## Approach

In the weekend branch, when `today.weekday() == 6`, use `sat = today - 1 day` so the
stored Sat..Sun period contains today — mirroring the week branch's Sunday guard.
«наступних вихідних» wording is out of scope (not currently parsed at all).
