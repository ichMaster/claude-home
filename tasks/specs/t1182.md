# t1182 — cal keeps only the first EXDATE line

## Problem / goal

Google Calendar emits one EXDATE line per deleted occurrence of a recurring event, and
RFC 5545 allows the property to repeat. The field collector uses `fields.setdefault`, which
keeps the **first** line of every property name — so with two deleted occurrences only the
first is excluded, and the second deleted occurrence reappears in the probe, the digest and
the reminders.

## Test cases

- **TC1 — regression:** a weekly event with two EXDATE **lines** (different weeks) lists
  neither excluded occurrence (fails before: the second week is listed).
- **TC2:** a single EXDATE line with two comma-separated dates still excludes both
  (the already-working form must not regress).

## Approach

Collect EXDATE into a list of `(params, value)` pairs instead of `setdefault`, and union
all their parsed dates into `excl`. Other properties keep first-wins, which is correct for
them.
