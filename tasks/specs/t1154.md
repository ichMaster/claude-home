# t1154 — ОСНОВА stops being sent

## Problem / goal

The owner, 2026-11-11: «там далі висилалася основа з різними градусами і положенням планет —
треба прибрати». `mood.send()` speaks `spoken()` and then sends the **whole** reading as text,
so ОСНОВА — degrees, formulas, weights — arrived in the chat even though the voice never read
it. v1 kept it there deliberately, as the only way to trace a claim back to the figure it came
from; that tracing belongs in the log, not in his morning.

## Test cases

- **TC1 —** `send()` delivers a reading with no `ОСНОВА`, no `°` and no `[pN]` marker, and
  still carries ДЕНЬ, ПРОГНОЗ and ДІЯ.
- **TC2 —** the log and the state keep the full reading, ОСНОВА and markers included — the
  audit trail is not what was removed.

## Approach

`mood2.send()` passes `spoken_part(text)` instead of `strip_marks(text)`: one function already
cuts at ОСНОВА and removes the markers. Nothing about the writing stage changes — the section
is still produced, still checked, still logged.
