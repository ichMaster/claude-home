# t1229 — part_of_day collapses a midnight-crossing window

## Problem / goal

`status/mood2.py` `part_of_day()`: `if end is None or end <= start: end = start + 1`
treats any window whose `to` lies past midnight (end-minutes < start-minutes) as one
minute long, so the documented majority-overlap rule degenerates to "the part containing
the start". `part_of_day("23:10", "03:12")` returns «ввечері» although the window spends
50 minutes in the evening and 192 in the night. Live data carries such windows — 4 of 43
timed windows in the current v2 log cross midnight — and the label feeds the writing
stage, so the spoken forecast places those states in the wrong part of the day.

## Test cases

- **TC1 —** `part_of_day("23:10", "03:12")` → «вночі» (regression; returns «ввечері»
  before the fix).
- **TC2 —** `part_of_day("22:22", "03:09")` → «вночі» (98 min evening vs 189 min night,
  a live window from the reference store).
- **TC3 — edge:** the boundary cases stay: `("18:00", "18:00")` → «ввечері» (a moment
  takes its start's part), `("23:00", "23:50")` → «ввечері» (no wrap when the window
  does not cross), and a wrap that still spends most of itself before midnight —
  `("19:00", "00:30")` → «ввечері».

## Approach

Treat `end == start` as the one-minute moment it always was; when `end < start`, add
24 h to `end` and score the PARTS twice — once as-is, once shifted a day — so «вночі»
competes for the after-midnight stretch. Ties keep preferring the earlier part, as now.
