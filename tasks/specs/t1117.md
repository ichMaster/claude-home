# t1117 — the scripts a person is told to run could not be run

Found by the owner, 2026-11-01. He typed what the login page and `CLAUDE.md` tell him to type:

```
$ ./panel/auth.py
/usr/bin/env: ‘python’: No such file or directory
```

## Problem

Every script in this project carries `#!/usr/bin/env python`, and this machine has `python3`
only. It never mattered: the timers, the session and the panel all invoke scripts as
`.venv-voice/bin/python <script>`, so the shebang was decoration. It mattered for the three
that the documentation hands to a **person** as `./something.py` — and one of those is the
only way to set the panel's password, which is the one thing standing between the panel and
nobody being able to log in.

Found while fixing it: `./tools/permissions.py list` printed «(локально)» for all seven
decisions, defaults included, because `levels()` returns the *merged* configuration and the
column asked it "is this set locally?".

## Fix

- `panel/auth.py`, `tools/permissions.py`, `tools/versions.py` → `#!/usr/bin/env python3`,
  and executable. All three are stdlib-only (`noosconf` included), so the system interpreter
  is enough.
- The other 40 scripts keep their shebang on purpose: they need the venv's packages
  (`pyswisseph`, `requests`, the embedding model), a shebang cannot point at a relative path,
  and they are never invoked directly. The test states that.
- `permissions.local_levels()` reads `config.local.json` alone, so «локально» means
  overridden and «типове» means the committed default.

## Test cases

- **TC1 —** each directly-run script's shebang names an interpreter that exists on PATH.
  (Fails before: `python` does not.)
- **TC2 —** each is executable.
- **TC3 —** running each through its own shebang produces no `No such file or directory`, no
  `ModuleNotFoundError` and no traceback.
- **TC4 —** the rest still run under the project interpreter.
- **TC5 —** a default permission level is not reported as a local override; no local file and
  a broken local file both mean "no overrides".
