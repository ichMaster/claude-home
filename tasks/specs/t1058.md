# t1058 — the panel has to be reachable from the owner's own machine

## Problem

Phase 1 bound the panel to `127.0.0.1`, reasoning that an SSH tunnel is the access control.
That reasoning forgot who the panel is for: the owner works from a different computer on the
same Wi-Fi, so loopback made it unreachable for the only person who uses it. He tried
`127.0.0.1:8091` (his own machine, connection refused), then `192.168.1.197:8091`
(connection timed out) before the cause was found.

Two causes stacked, and they looked the same from his side:

1. **The bind address.** Loopback only — no address on the LAN could reach it.
2. **`ufw`.** The firewall is enabled on this machine and silently drops inbound 8091, which
   is why the symptom changed from *refused* to *timed out* rather than clearing. The
   matrix-agora panel on 8090 is reachable because Docker publishes it and Docker writes its
   own rules past ufw — a plain Python process gets no such help. This is worth writing
   down: every future port this project opens needs an explicit `ufw allow`.

## Test cases

- **TC1** — `resolve_host()` passes a literal address through unchanged.
- **TC2** — `resolve_host("tailscale")` asks Tailscale for this machine's tailnet address,
  so the address is resolved at start rather than frozen into the config, where it would
  become a unit that refuses to boot the day the address changes.
- **TC3** — with Tailscale absent or failing, `resolve_host("tailscale")` falls back to
  loopback and says so: a panel listening somewhere safe beats a unit that will not start.

## Approach

`panel.host` now takes a literal address, or the word `tailscale`. The owner chose
`0.0.0.0` — every device on the local network — after being told plainly that the board has
no authentication; that decision and its alternatives are recorded in the config's own `_`
note, where the next person to read it will find them.

The firewall rule (`sudo ufw allow 8091/tcp`) is the owner's to apply and was: the session
has no root and does not ask for it.

Out of scope: authentication. The design says that if the panel ever needs to be reachable
beyond a trusted network, that is a version of its own and not a checkbox — opening it to
the LAN does not change that, it only moves the trust boundary to the Wi-Fi.
