# t1169 — genitive weekday forms after «до» parse to a due date

## Problem / goal

`parse_due` matches weekdays against the `DAYS` dict, which holds only nominative and
accusative forms (`п'ятниця`, `п'ятницю`, `пт`, …). After the preposition «до» Ukrainian
requires the genitive — «до п'ятниці», «до понеділка», «до середи», «до четверга»,
«до суботи», «до неділі», «до вівторка» — and none of those forms are in the dict. The
module's own docstring example (`add "полагодити індексацію до п'ятниці"`) therefore returns
`(None, unchanged title)`: the task is created with no due date, lands in the backlog, the
tasks probe never flags it, and the date phrase stays in the title — all silently.

Found by the nightly code review of 2026-11-13 (Medium), verified by executing `parse_due`.

## Test cases

- **TC1 —** `parse_due("полагодити індексацію до п'ятниці")` returns the coming Friday and
  the title without the phrase (the docstring's own example; regression — fails before the
  fix).
- **TC2 —** every genitive weekday («до понеділка», «до вівторка», «до середи»,
  «до четверга», «до суботи», «до неділі») returns the matching coming weekday.
- **TC3 — edge:** the apostrophe variant «до пʼятниці» (U+02BC, as the dict already carries
  for «пʼятницю») parses too.
- **TC4 —** existing forms still work: «у п'ятницю» keeps returning Friday.

## Approach

Add the genitive forms to `DAYS` (both apostrophe variants for п'ятниці), nothing else. The
regex is built from the dict's keys, so no other change is needed.
