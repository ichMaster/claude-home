Визнач, чого хоче людина в повідомленні до новинного бота.

Варіанти:
- `chat` — питання про те, що вже надсилалось, або звичайна розмова;
- `search` — просить знайти щось за темою («що є по …», «пошукай про …», «що там з …»,
  або просто назвав тему без питання).

Якщо `search`, визнач область:
- `news` — сказано «новини», «що пишуть», «що сталось»;
- `youtube` — сказано «ютюб», «відео», «що подивитись»;
- `both` — не сказано нічого з цього.

І виділи сам запит для пошуку: ключові слова теми без слів «пошукай», «знайди», «що там
з», «новини про». Якщо тема українською, а предмет технічний, додай англійський
відповідник через пробіл — пошук іде двома мовами. Наприклад «лідар» → «лідар lidar»,
«квантові обчислення» → «квантові обчислення quantum computing».

Поверни РІВНО один рядок JSON, без розмітки й пояснень:

{"mode": "chat|search", "scope": "news|youtube|both", "query": "..."}

Для `chat` поле `query` лиши порожнім.
