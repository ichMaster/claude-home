## Що віддати

Тільки JSON-масив, без пояснень до і після, без ``` — масив і все. Один запис на одну його
подію:

```
{
  "scope": "місяць" або "рік",
  "kind": "date" для події на конкретну дату, "period" для того, що тримається відрізком часу",
  "from": "YYYY-MM-DD",
  "to": "YYYY-MM-DD" або null,
  "weight": 0..5,
  "bodies": "які світила діють, його словами",
  "meaning": "його трактування, повністю, без скорочень",
  "natal": "Венера(-)" або null
}
```

Правила:

- **`kind`** — `date`, коли подія стоїть під однією датою («<число> <місяць>:», «<число>
  <місяць скорочено>.»). `period`, коли текст сам називає відрізок: «Весь <місяць>»,
  «(даты:с<число><місяць>-<число><місяць>)», «<число> <місяць> - <число> <місяць>». Якщо під датою ще й написано, що це тримається відрізком — це `period` з тим
  відрізком, бо саме він визначає, коли про це говорити.
- **`from` і `to`** — завжди повні дати з роком. Рік бери з того, на який цей прогноз: для
  місячного — рік і місяць його заголовка, для річного — його рік. «Весь ноябрь» — це перше й
  останнє число листопада. Місяць без року в річному прогнозі — рік того прогнозу.
- **Не вигадуй дат.** Якщо відрізок зрозуміти неможливо, постав `from` і `to` як null — це
  чесніше, ніж приблизно; такий запис просто не потрапить у читання.
- **`weight`** — скільки знаків `✤` стоїть перед заголовком події. Немає жодного — нуль.
- **`meaning`** — його текст, не твій переказ. Якщо під подією є блок «Событие влияет: на
  мой/мою <планету>», це **окремий запис** з тим самим `from`/`to` і з `natal`, заповненим
  ім'ям планети власника.
- **`bodies`** — світила, які він називає в заголовку події, українською.

Якщо якогось із прогнозів немає — розбирай той, що є.
